# SkillCraft Technology - Web Development Internship

## Task 01 - Responsive Landing Page

### Project Overview

This project was developed as part of the SkillCraft Technology Web Development Internship.

The objective of this task was to create a responsive landing page with an interactive navigation menu that changes style when scrolling and provides hover effects for menu items.

### Features

- Fixed Navigation Bar
- Scroll-Based Navigation Styling
- Interactive Hover Effects
- Active Navigation Link Highlighting
- Smooth Scrolling
- Responsive Design for Mobile and Desktop
- Functional Get Started Button
- Modern Gradient Backgrounds

### Technologies Used

- HTML5
- CSS3
- JavaScript
